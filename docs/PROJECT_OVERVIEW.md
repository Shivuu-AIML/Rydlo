# Project overview

Rydlo is a peer-to-peer marketplace for renting bikes and cars in one launch city. A single account can eventually act as both renter and owner. The product experience is centered on direct handover, clear communication, online payment, and a commission on successful bookings.

## M0 scope

M0 establishes the product shell only:

- A responsive Minimal Luxury homepage
- Visual search, featured demo vehicles, categories, owner onboarding, and trust sections
- Placeholder routes for discovery, sign in, registration, and owner listing
- An independently runnable API with a health check
- PostgreSQL and Prisma configuration with no business tables yet

Authentication, booking, payment, chat, calls/WhatsApp, vehicle management, and commission logic are intentionally deferred.
