# Design system

Rydlo uses a Minimal Luxury visual language: spacious, editorial, warm, and confident without unnecessary decoration.

## Tokens

| Purpose | Value |
| --- | --- |
| Background | `#F7F6F2` |
| Surface | `#FFFFFF` |
| Primary | `#20201E` |
| Secondary text | `#77766F` |
| Border | `#D9D5CA` |
| Accent | `#9A7653` |

## Typography

- **Manrope** is used for interface text, labels, navigation, and supporting copy.
- **DM Serif Display** is used for editorial headlines and high-emphasis moments.

## Components

Buttons use full rounded corners and clear contrast. Cards use restrained borders and generous radii. Inputs use visible labels and focus borders. Layouts use a centered `Container` with responsive horizontal padding.

Imagery is high-contrast automotive photography with subtle overlays for legibility. Motion is limited to small hover transitions and a restrained Framer Motion-ready dependency; the M0 homepage avoids animation that distracts from navigation or content.

## Accessibility

Interactive elements use native buttons and links, images have descriptive alternative text, focus states are preserved, and responsive layouts remain usable from mobile through desktop widths.
